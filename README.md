# Gas-Detecting and Obstacle-Avoiding Robot

This project is a mobile robot built to detect potentially hazardous gases and avoid obstacles while moving. It uses an Arduino Nano, gas sensors, an ultrasonic sensor, an L298N motor driver, and a servo motor for sensing and movement control. An LCD displays relevant information, while the system provides alerts when gas levels exceed a defined threshold.

**Technologies:** Arduino, C++, Arduino IDE, Gas Sensors, Ultrasonic Sensing, Embedded Systems.

**Purpose:** To explore robotics, environmental monitoring, and autonomous navigation for potentially hazardous environments.
